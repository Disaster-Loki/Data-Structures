# 🚀 Data Structures Projects

Welcome to the **Data Structures Projects** repository! This collection of projects explores various fundamental data structures, each implemented in different scenarios and use cases. Whether you're learning, teaching, or practicing data structures, this set of projects offers a comprehensive dive into stacks, linked lists, queues, trees, graphs, and more! 🌐

## 📦 Project List

### 🥞 **Project Container (Stack)**
- **Description**: The Stack project showcases how the stack data structure works, following the Last In, First Out (LIFO) principle. Here, we simulate containers being stacked and removed, ideal for situations where reversibility and order of processing are key.
- **Key Concepts**: 
  - Push/Pop operations
  - Stack overflow and underflow
  - Practical applications: undo operations, expression evaluation

### 🚚 **Project Truck (Doubly Linked List)**
- **Description**: This project introduces the **Doubly Linked List**, where each node holds a reference to both the next and previous nodes. In the truck analogy, we simulate cargo that can be loaded and unloaded from either side, ensuring easy traversal in both directions.
- **Key Concepts**:
  - Node insertion and deletion
  - Bidirectional traversal
  - Use cases: browser history, music playlist navigation

### 🎶 **Project PlayList (Doubly Circular Linked List)**
- **Description**: Imagine a playlist that loops indefinitely! This project demonstrates a **Doubly Circular Linked List**, where the last node points back to the first, creating a circular structure. Perfect for modeling playlists, continuous loops, and round-robin scheduling.
- **Key Concepts**:
  - Circular traversal
  - Efficient list cycling
  - Endless loops: round-robin task management, media playlists

### 🌀 **Project Tsukugome (Queue, Stack, Circular List, Binary Tree, Graphs)**
- **Description**: The most ambitious project in the collection! 🎮 **Tsukugome** combines multiple data structures to manage complex game mechanics, including **Queues** for managing tasks in order, **Stacks** for action history, **Circular Lists** for continuous game loops, **Binary Trees** for hierarchical decision making, and **Graphs** for representing game maps and networks.
- **Key Concepts**:
  - Queues for turn-based actions
  - Stacks for undo/redo systems
  - Binary Trees for AI decision-making
  - Graphs for pathfinding and world representation
